# 城市库存、物流与外交试玩

```powershell
.venv/Scripts/python live_server.py --load examples/civil_networks/save.json --paused --open
```

选择“继续游戏”，再在左栏选择“国家A”并介入。A 有两座城市；点击“物流”图层，左栏列出各城库存与可供天数，点城市可查看路线、运量与损耗。

外交页可提议贸易协定、开放边境、军事通行或同盟，也可终止已生效协定。关系门槛分别为 15/25/40/60。提案需要对方接受，等待 AI 的下一次规划，或切换治理国手动回应。

军队用现有军事页招募后，可在地图直接点击选中，再点目的地查看预估路线和天数。战斗、围城参数保持军事分支方案。

本存档为原 seed 50002 世界的独立副本，通过正常建城动作生成。依赖同一仓库的 `examples/hexfirst/world.json`；保存时会另建本机槽位。
