# 军事玩法与规则

本页说明军事更新后的操作和默认数值。README 与开发手册中描述旧版本的军事数据仍用于历史对照。

## 玩家操作

- 在地图上选地块，再选择驻守或进攻。选择兵种数量时，面板使用全国可调遣的城市守军库存。
- 已出征部队占用独立番号。默认可派第一支军队，军事科技 3 级和 5 级分别解锁第二支和第三支。
- 选中下令对象后，直接点击地图。己方或无主陆地可以驻守。获准军事通行的外国陆地也可驻守。交战地块或敌方野战驻军发起进攻。点击本国城市回城，抵达后将剩余兵力入库并释放番号。
- 已出征的军队从当前位置改令。派援军占用空闲番号，抵达后并入指定驻军。地图上的「取消下令」退出直接下令模式。
- 在兵营先选兵种，再开始招募。暂停保留进度。每批成兵 10 人，自动进入距离兵营最近的本国城市。城防储备在城市中心遇袭时参战。

## 默认规则

| 项目 | 数值 |
| --- | --- |
| 行军 | 每日推进 0.05 点，单令最多 60 点。草原 1 点/格，道路 0.35 点/格，林地 5 点/格，雨林 12 点/格，高山 16 点/格。未经许可的外国地块额外 1.25 点。 |
| 敌境作战 | 对处于敌国领土的部队乘 0.8 战力，普通战斗和围城都使用该系数。 |
| 训练 | 民兵、弓箭手、战车、重步兵、骑兵、攻城兵各需 260、320、390、470、560、700 日。开训后每营每天付 0.01 财政。 |
| 养护 | 已成兵按兵种耗粮。每批每日口粮分别是 0.0288、0.032、0.0448、0.04、0.0528、0.0576。生效对象包括城市守军与出征部队。 |
| 旧版会师容量 | 仅用于旧命令兼容。普通格为在营兵营数乘 14，都城在此基础上额外加 14。新版派兵以番号和实际可用兵力为限。 |

路线上每格成本由引擎报价。道路施工须满足上游的道路连通、科技、河道和外交条件。
